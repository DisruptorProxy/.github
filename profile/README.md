VLESS, VMess, Trojan, Shadowsocks, Hysteria2, and TUIC - including REALITY - in a native desktop
and mobile app. Add a subscription once and the server list keeps itself current; latency-test
thousands of servers and sort by what actually measured fast; route by domain, GeoIP, GeoSite, IP
range, or process name. The connection status is the thing you care about, so it's the first thing
you see.

### Where things live

| Repository | What it is |
| --- | --- |

| **[Xray-Client](https://github.com/DisruptorProxy/Xray-Client)** | Downloads. Every release, and what the in-app auto-updater fetches from. |

### Get it

Grab an installer from **[Releases](https://github.com/DisruptorProxy/Xray-Client/releases/latest)**.
The app updates itself in place, so this is a one-time download.

### Highlights

- **Built for scale** - thousands of servers stay smooth: virtualized rendering, instant search,
  filters by protocol and source.
- **Real health data** - latency results persist and drive sorting, not a one-off ping.
- **10 languages** - including full right-to-left layout for Persian and Arabic.
